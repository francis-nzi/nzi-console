Path to SRS-readyOpen gaps, highest priority first — each ready to turn into a dated action.
Reassessment → trendEach completed assessment adds a point; the line appears on reassessment.
Review & reassess loop. An assessment is dated on completion and carries a next-review date — annual by default, or biannual, a custom date, or off. When it falls due the CRM is auto-reminded; the CRM reopens the latest completed assessment (a new version — every change timestamped, ID'd and audited), reassesses, and the point joins the trend. The client can request a review any time via portal messaging.

iPrinciples
Consultant-led (NZC-022). Staff run the assessment and curate the plan — they are the independent review. The client reads scores and evidence and can message, but never edits the assessment.
AI is a suggestion, not a fact. Gap-bridging AI proposals are staff-curated before a client or the library ever sees them.
Client data is verified. Everything is imported from client records and V7, so Auto allocation scores from verified data — no “unverified” caveats.
Gaps → actions is one spine. An SRS gap and a plan action are the same library item, so Readiness and Reduction Strategies stay aligned.
Auto-reminders, system-wide. Review dates, action due dates and milestones all remind through one pipe — sensible defaults, flexible per client. Built case by case first, then generalised into one registry.
